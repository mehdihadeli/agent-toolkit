# Agent Toolkit Documentation Research Plugin

Reusable agent skill for researching official documentation and converting relevant findings into a concise implementation checklist.

## Skill

### `docs-research`

Use when implementation guidance depends on external library, framework, SDK, API, CLI, or cloud-service documentation. The skill prioritizes primary sources, checks version-specific constraints, cites critical findings, and calls out unknowns instead of guessing.

The skill is tool-agnostic. It can work with `agent-toolkit-search`, Microsoft Learn, Context7, or other documentation tools available to the host agent.
