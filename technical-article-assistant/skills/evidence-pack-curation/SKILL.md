# Evidence Pack Curation

Build an evidence pack that makes a technical article trustworthy.

## Collect

- Official documentation and specifications
- Architecture references and ADR-style decision inputs
- Operational constraints and production caveats
- Benchmarks, limits, quotas, or runtime behavior when relevant
- Code examples or pseudocode that can be explained clearly

## Organize

- Separate authoritative sources from opinionated references.
- Note where the article depends on assumptions rather than verified facts.
- Capture diagram ideas: context, containers, sequence, deployment, or failure-path views.
- Record open questions that must be resolved before publication.

## Output Format

- Source list
- Key claims supported by each source
- Diagram candidates
- Gaps and risks
